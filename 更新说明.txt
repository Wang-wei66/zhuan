安考通 GitHub 版 · 云端同步更新包
==========================================

本次更新：
  - 安考通新增「自定义同步服务」：GitHub Pages 上的安考通也能跨设备同步
    答题记录、笔记、错题本（数据存到你自己的在线同步服务）
  - 选择页升级为智能入口：自动适配目录结构

上传方法（GitHub 网页 → 仓库 → Add file → Upload files，同名自动覆盖）：
  把本目录下全部文件拖进去提交：
    index.html        智能选择页
    za/index.html     安考通新版
    index (3).html    安考通新版（当前仓库拍平文件名）
  提交后等 Pages 构建 1-2 分钟。

开启同步（每台设备操作一次）：
  1. 打开安考通 →「我的」→ 云端同步 → 自定义同步服务
  2. 填入在线同步版服务地址（含 sharecode）：
     https://a5224516971475f50.app.workbuddy.host/za?sharecode=你的分享码
  3. 点「保存并连接」，同步状态变绿即成功；
     其他设备填相同地址 + 相同同步码，记录自动汇合。
  4. 或直接复制 App 内「同步链接」到另一台设备浏览器打开，一键接入。

说明：
  - 在线同步版与 GitHub 版共用同一份云端数据，互通无阻
  - 不填自定义服务时，GitHub 版保持纯本机模式（数据只存当前浏览器）
  - 单文件版双击打开 + 填自定义服务，同样可以同步
