1关于学习数据

两个 App 均已接入云端同步：打开后自动连接同步服务，答题记录、笔记、错题本、收藏、打卡等即时上传，同一同步码的多台设备记录自动汇合去重。

想合并两台设备的数据：在旧设备「我的 → 云端同步」复制同步码，到新设备「加入另一台设备」填入即可。云端不可用时自动降为本机保存，恢复后补传；建议仍定期导出 JSON 备份。

2iPhone 添加到主屏幕

  1. 用 Safari 打开「安考通」或「素学」页面
  2. 点底部「分享」按钮
  3. 选择「添加到主屏幕」
  4. 确认名称后点「添加」

桌面会出现独立图标，点开即全屏运行，没有浏览器地址栏。
